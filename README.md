# Creative-Coding-assignment-Hotel-Art-Reno
This is part of my creative coding class assignment. 
##General Information
This project is a collection of artworks that I have coded that are designed to be placed in hotel rooms. There will be four artworks sets all together, one for the bedroom, lounge, bathroom and kitchen. These will be designed and coded to accommodate human emotions and psychology, with the colours and shapes used designed to achieve certain mood from people.
##Technolgy
This project was done with Processing, using Java script.
